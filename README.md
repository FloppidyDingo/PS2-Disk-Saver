## About this mod
The Playstation 2 Slim models have a flaw where the glue holding the laser ribbon will get old and fail. This causes the ribbon to curl up towards your disks, eventually touching them and scratching them. A common fix is to apply more glue or replace the ribbon. This however I feel is a bandaid fix as there is still glue that can eventually go bad and the problem returns.

This mod is meant to be a permanent fix for this problem. It is a shield that you attach to the laser itself that holds the ribbon down, creating a physical barrier that prevents the ribbon from touching your disks. It is simple to install, cheap, and if you have a 3D printer, easy to make yourself. This mod is a must have for your PS2 Slim, as it protects your games without hurting console functionality.

If you are printing from this source, you will need to print one of Laser Guard.stl and one of Ribbon_Shield_V5.stl

Installation instructions here: https://github.com/FloppidyDingo/PS2-Disk-Saver/wiki/Installation-Instructions

You can buy premade kits here: https://www.etsy.com/listing/1260716684/playstation-2-disk-saver-ribbon-shield

## A warning before you get this!
There have been reports of an incompatibility with some PS2 7500x models. This is due to these having a different laser than other slims. Before you get this mod, please check your laser to see if it is compatible. Below is a guide to tell you which one will work. DO NOT ask me to verify for you, I will be unable to tell off the model number alone.

## Recommended print settings:

  - Material: ABS or PETG (Avoid PLA as it can warp easily). Use the recommended temperature for your material, aim for the higher side of the temperature range

  - Print speed: 30mm/s recommended for the ribbon shield, any speed will do for the ribbon guard but slower is better overall

  - Layer height: 0.1mm recommended, 0.2mm will work too

  - Supports: Yes, also recommended to drop support to model gap to 1 layer instead of the standard 2 layers

  - Any infill will work

  - 3 wall loops recommended

  - If the ribbon shield comes out malformed, try decreasing the speed or increasing the support density. It can also help to use the part cooling fan when printing overhangs if your slicer supports that option
